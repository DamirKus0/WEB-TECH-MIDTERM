# Micro-Loan Platform

Учебный сайт на HTML5, CSS3 и Bootstrap 5 через CDN. Откройте `index.html` в браузере с доступом к интернету.

Форма `apply.html` содержит Personal Details, Financial Information и Loan Details. Проверка выполняется средствами HTML5: обязательные поля, формат email, доход от $0, сумма займа $100–$5,000 и цель длиной 10–300 символов.

Submit Application выполняет обычный demo-переход через `form action="success.html"`. JavaScript и backend отсутствуют. Страница `success.html` создаётся следующим этапом после commit формы.
