# Micro-Loan Platform

A simple micro-loan website created for a Web Technologies midterm project.

## Features

- Home page with loan benefits and a demo calculator interface.
- Loan application form with built-in HTML validation.
- Application confirmation page.
- Borrower dashboard with sample loans and payment information.
- Loan details and repayment schedule.

## Getting Started

Open `index.html` in your browser. No installation or build tools are required. An internet connection is needed to load Bootstrap from the CDN.

## Project Structure

- `index.html` — Home page.
- `apply.html` — Loan application form.
- `success.html` — Submission confirmation.
- `loans.html` — Borrower dashboard.
- `loan-details.html` — Loan details and repayment schedule.
- `css/style.css` — Custom styles.
- `css2/style2.css` — Dashboard and loan details styles.
